# مهر و مرز · MehrVaMarz

Website for **بیان امن و اثربخش · Safe and Effective Expression**: free Farsi/English games, lessons and skills for compassionate, safe and effective communication.

Based on the work of Dr. Marshall Rosenberg and the Center for Nonviolent Communication (cnvc.org). This is an independent project and is not affiliated with or endorsed by CNVC.

## Structure

- `index.html` — the whole site (pages, games and card content) in one file.
- `.nojekyll` — tells GitHub Pages to serve the file as-is.

## Publishing

The site is served by GitHub Pages from the `main` branch. Any change pushed to `main` goes live within a minute or two.
